# Market artwork

`market-cover.png` is the user-selected market and README cover. The plugin logo is `../logo.png`, resized from the separately selected image to 256×256 without cropping.

`screenshots/player.png` and `screenshots/listening-journal.png` are interface screenshots supplied and selected by the maintainer for the README. The player screenshot is cropped to the main player area to exclude the account portraits below it. These v1.3 screenshots illustrate the interface; they are not evidence of a clean v1.4.0 installation test. Album artwork remains part of the captured interface and is not distributed as separate artwork assets.
